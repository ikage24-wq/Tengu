# Effect art credits

Every effect strip in this folder is Tengu's own art, drawn for the game in `tools/fx-art.js` and
built by `tools/build-fx.py` (matched to the sprites' pixel size and outlines). No outside effect
packs are used.

If an outside pack is ever added, credit it here, and only use packs whose license allows
shipping their files in the game's own files (CC0 or CC BY, with credit).
